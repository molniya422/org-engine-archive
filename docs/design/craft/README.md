# Org Engine Editor — Craft Rules

Brand-agnostic craft knowledge for the project. Each file covers one dimension of professional UI craft.

## Index

| File | Section | When to reference |
|---|---|---|
| `color.md` | Color discipline | Any UI work touching accent, background, or palette decisions |
| `typography.md` | Typography | Any UI work setting type sizes, tracking, or font choices |
| `animation.md` | Animation | Any UI work with transitions, springs, or reduced motion |
| `anti-ai-slop.md` | Anti-AI-slop | Guard against common LLM-generated UI tells |

## Design Tokens (source of truth)

All color and spacing tokens live in `frontend/src/styles/globals.css`. The craft rules below tell you *how* to use those tokens, not which values to set.
