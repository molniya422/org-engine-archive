# 个人学习策略（P7.4）

本文回答一个问题：**系统从你的行为里学什么、不学什么。** 核心边界：

> 学习的是「规则」——你反复确认过的偏好，写成可读、可拒、可回滚的配置；
> 不学习的是「模型」——本阶段绝不基于你的数据微调任何模型（见
> [model-adaptation-gates.md](./model-adaptation-gates.md)）。

## 1. 学什么（学习规则）

学习层（`engine/personal/learning/`）只消费五类行为信号：
accepted、edited、rejected、revoked、repeated_correction。升级为候选规则
必须同时满足：

1. **重复且一致**——同一字段向同一方向的修正至少出现 `MIN_REPEAT`（2）次；
2. **可追溯**——每条信号关联 task、trace、evidence，能还原到原任务；
3. **已脱敏**——正文写入前脱敏；高敏感信号只保存事件类型，永不进入候选。

## 2. 不学什么（硬边界）

| 行为 | 状态 |
|---|---|
| 单次拒绝推断长期偏好 | **禁止**（P7.2 规则 1） |
| 高敏感信号参与规则生成 | **禁止**（只存事件类型） |
| 未经批准的规则影响任何任务 | **禁止**（默认 proposed） |
| 学习层直接改写任务/规则/权限 | **禁止**（必须走提案→批准→回归→版本） |
| 用行为数据微调模型 | **本阶段禁止**（见下） |

## 3. 规则与模型的边界

「学习规则」是**配置变更**：修改 facts/rules/policy/prompts，产物是可读的
when/then 规则，人可以逐字审阅、拒绝、回滚（P7.3 版本账本）。

「训练模型」是**行为变更**：改变系统在任何输入上的生成方式，产物无法逐字
审阅、无法局部回滚。两者不可混用——**凡是可以用规则表达的偏好，一律用
规则表达，不进入任何训练流程。**

## 4. 成为模型训练数据之前必须满足的全部条件

即使是远期的模型适配，也必须逐条满足（详见 model-adaptation-gates）：

1. **明确选择加入（opt-in）**——不勾选，不开始；默认关闭。
2. **可导出**——用户随时能导出/删除自己的训练数据集。
3. **个人 eval 稳定**——回归集连续多轮通过后才允许实验。
4. **并行回放**——微调模型与原模型对同一批历史任务并行回放，逐项比较，
   不劣于原模型才允许替换。
5. **审计保留**——每次替换记录版本、eval 报告、回滚方法。

## 5. 用户随时拥有的权利

- 查看每条候选规则的「为什么」（例子、范围、反例、风险）；
- 拒绝任何提案而不影响进行中的任务；
- 一键回滚任何已启用的规则版本；
- 导出全部学习事件，或删除全部学习历史。
